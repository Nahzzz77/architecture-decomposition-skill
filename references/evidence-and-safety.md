## 1. 证据等级

在单份报告内固定使用一套标签；跨报告保持语义一致。

| 通用语义 | 页面审查用语 | 架构报告用语 | 判断标准 |
|---|---|---|---|
| 直接证据 | 【页面事实】 | 【已确认】 | 页面、只读展开内容、已保存截图或官方资料直接支持 |
| 行为推导 | 【合理推断】 | 【合理推断】 | 至少两条直接证据共同支持，但无法直接看到内部实现 |
| 设计补充 | 【建议规则】 | 【建议设计】 | 为稳定、安全、可审计或可复现而提出，原产品未证明 |
| 证据不足 | 【尚未确认】 | 【未知】 | 当前范围未出现、无法安全验证或证据互相冲突 |

不要把“没有观察到”改写为“产品没有”。不要用推断填补证据表中的直接事实栏。

## 2. 只读操作边界

### 允许

- 打开目标页面、滚动历史、展开折叠消息或公开运行详情。
- 查看已存在的文本、附件、媒体、响应卡、任务状态和错误。
- 打开已有预览、只读详情、模式菜单或模型菜单，前提是不会创建新任务或写入状态。
- 查看导航、历史、搜索、排行榜入口和当前可见列表。
- 保存截图并打开复查。

### 禁止

- 发送、编辑后提交、重新生成、重试、运行 Agent、创建新对话。
- 投票、改变投票、评价、反馈、举报、发布、分享或下载。
- 删除、购买、充值、修改账号或切换可能丢失当前上下文的模式。
- 查看 Cookie、Token、密码、鉴权头、浏览器存储、网络请求密钥或个人敏感信息。
- 根据回答风格猜匿名模型、私有算法、System Prompt、隐藏思维链或后端技术栈。

若无法判断按钮是否会写入状态，保留入口证据但不要点击。

## 3. 取证顺序

1. 记录页面标题、URL、登录可见性、当前模式和初始状态。
2. 记录导航、历史、搜索、排行榜、输入占位、附件、模型和输出类型入口。
3. 滚动到最早一轮，按时间顺序记录用户输入、附件、模型/槽位、响应和状态。
4. 检查每个结果的文本或媒体是否实际存在，而非只信“完成”文案。
5. 检查用户可见决策点：继续、编辑、选择、评价、重试、中断、返回历史。
6. 检查失败、超时、安全、权限、额度、频率、空结果和状态冲突。
7. 回看历史与当前页面，确认轮次、模型标签、评价/揭晓和资产归属是否一致。

## 4. 证据与截图格式

### 截图编号

使用 `S01`、`S02`……。每张截图保存后必须重新打开，排除：空白、加载中、系统弹窗遮挡、裁切关键控件、缩放失真或包含敏感信息。

截图清单字段：

| 截图编号 | 页面状态 | 可见范围 | 支持证据 | 复查结果 |
|---|---|---|---|---|

### 证据编号

使用 `E01`、`E02`……。每条证据至少包含：

| 字段 | 内容 |
|---|---|
| 页面原文 | 逐字记录关键文案；长文本只摘取必要短句 |
| 控件 | 按钮、菜单、输入框或状态组件名称 |
| 模式 | 页面明确模式；不明确则写未知 |
| 模型/槽位 | 真实可见名称或“候选槽位 A/B” |
| 响应/资产 | 文本、图片、视频、音频、文件、空结果 |
| 状态/错误 | 加载、完成、失败、中断、错误原文 |
| 截图 | 对应 `Sxx`；无截图时说明原因 |
| 来源位置 | URL、会话轮次或页面区域 |

侧边栏其他会话标题不得当作当前会话证据。

## 5. 冲突处理

以下冲突必须单列，不得自行消解：

- Agent/页面声称完成，但结果或媒体资产缺失。
- 聊天文字、任务状态、响应卡、画布/资产历史不一致。
- 投票状态、模型标签、揭晓状态和历史记录不一致。
- 两个槽位疑似使用了不同输入、附件或上下文。
- 编辑上游输入后，旧响应仍显示但有效性未知。
- 用户中断后页面仍显示运行，或页面停止但后台状态未知。

冲突条目使用：`冲突对象 → 证据 A → 证据 B → 用户影响 → 当前可确认边界`。

## 6. 隐私与敏感信息

- 报告不得包含 Cookie、Authorization、Bearer Token、API Key、密码、验证码、浏览器存储或鉴权头。
- 截图出现账号邮箱、真实姓名、头像、私人会话标题或附件名时，若与结论无关应遮挡或裁切。
- 不复制浏览器开发者工具中的网络请求、请求头或存储内容。
- 上传包只复制报告明确引用的资源，不打包整个浏览器资料目录或无关截图目录。
- 使用 `scripts/validate_report.py` 扫描明显敏感模式，但人工复查仍是必需步骤。

## 7. 官方资料

- 只有在用户允许且页面证据不足时补充外部资料。
- 仅使用产品官方网站或官方文档；与页面证据分开编号，例如 `O01`、`O02`。
- 官方宣传可支持“官方声称的能力”，不能自动证明目标会话已经执行该能力。
- 引用应靠近结论，并写明访问日期和直接链接。
